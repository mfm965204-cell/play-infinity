Install in three steps

  1. Download the APK Tap the download button above. The file is about 14 MB.
  2. Allow the install Android will offer “Settings → allow from this source”. Accept it once.
  3. Open and watch The app registers this device on first launch and loads the catalogue.

Play Protect may warn about an app installed outside the Play Store — that is expected for sideloaded builds. Choose “Install anyway”.

Questions

Do I need an account?

No. There is no sign-in anywhere in the app. The device is identified by a random id created on first launch.

Why does Android warn me?

The APK is signed with a build key rather than distributed through the Play Store, so Play Protect flags it. Install anyway if you trust the source.

A live channel won't play

These are public IPTV restreams — some are geo-locked or simply offline. The player retries six times before showing an error; try another channel or import a different provider from the studio console.

Will I get updates?

Catalogue changes, banners and settings arrive instantly. A new APK has to be installed manually.
